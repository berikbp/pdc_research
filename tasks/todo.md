# План: гибридный CPU–GPU инференс, этап 1 (ноутбук Берика, Pop!_OS)

RQ1: при каких условиях CPU+GPU обгоняет GPU-only и сдвигает ли язык запроса эту границу.
RQ2: хватает ли для выбора конфигурации политики, знающей только длину последовательности.
Учитель направление одобрил (сообщено 15.11.2026).

## Шаг 2. Подробный sweep по слоям, 7B
- [ ] Разобраться с `-ngl 0`: сервер держит 174 МиБ VRAM и грузит GPU на 30–50%, это не чистый CPU; нужен настоящий CPU-only (без CUDA-устройства)
- [ ] Все `-ngl` от 0 до 29, 8 потоков
- [ ] Разбор логов сервера: какие слои на каком устройстве (проверить, что g28 оставляет на CPU только выходной слой)
- [ ] Модель стоимости: время слоя на CPU, на GPU, цена пересылки
- [ ] Перебор потоков в конфигурациях с слоями на CPU (код Берика переиспользуется)
